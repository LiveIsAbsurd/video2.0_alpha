Файлы шифруются с помощью openpgp, расшифровка с помощью библиотеки openpgp.js.

Проблемы:
1. В данной библиотеки нет возможности отображения прогресса расшифровки, в качестве решения я писал скрипт, который шифрует файл отдельными чанками, в одной реализации чанки сохранялись отдельными файлами, в другой соединялись в один файл, но таким образом увеличивался размер зашифрованного файла на ~10-20% из-за служебных данных, указывающих начало каждого чанка. (методы решения: поиск других библиотек или методов шифрования).
2. Из-за ограничений в памяти библиотека не смогла расшифровать файл размером 1.1гб, предполагаемое решение так-же поиск другой библиотеки

Предполагаемые улучшения:
1. Использовать pgp только для шифрования и расшифровки основного ключа, а сами файлы шифровать с помощью aes-256. Зашифрованный ключ хранить на сервере вместе с файлом, это увеличит скорость расшифровки и вероятно позволить добавить прогресс бар расшифровки
2. При расшифровке страница зависает, пока браузер занят расшифровкой, можно вынести эти вычисления в web worker, чтобы расшифровывать их в фоне.
